# МИСИС Два Миллиона - Медицинский ассистент для анализа анамнеза беременных

FastAPI приложение для суммаризации анамнеза пациенток на основе данных для врачей-акушеров

## Требования

- Python 3.8+
- Запущенная локальная LLM сервер (например, Ollama, vLLM, или другой совместимый с OpenAI API)

## Установка

1. Клонируйте репозиторий:
```bash
git clone 
cd lct2025-llm
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate 
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Настройка

### Переменные окружения

Поменяйте переменные окружения в dockerfile:

```bash
MODEL_PATH="your-model-name"

# URL локального LLM сервера (по умолчанию "http://localhost:8005")
LLM_SERVER_URL="http://localhost:8005"
```

## Запуск

1. Убедитесь, что локальная LLM запущена и доступна по адресу `http://localhost:8005`

2. Запустите приложение:
```bash
python main.py
```

Приложение будет доступно по адресу: `http://localhost:8001`

## API Endpoints

### `POST /chat`
Отправка данных для анализа анамнеза

```bash
curl -X POST "http://localhost:8001/chat" \
     -H "Content-Type: application/json" \
     -d '{"message": "Пациентка 28 лет, срок беременности 38+2 недели по УЗИ..."}'
```

**Пример ответа:**
```json
{
  "response": "## Срок беременности\n- 38+2 недели\n- По УЗИ I триместра\n\n## Родовой анамнез\n- Первородящая\n\n## Текущая беременность\n- Один плод\n- Осложнения: нет информации\n..."
}
```

## Примечания

- Приложение настроено для работы с русскоязычными медицинскими данными
- LLM должна поддерживать OpenAI API совместимость
- Рекомендуется использовать модели с размером не менее 7B параметров для качественного анализа
